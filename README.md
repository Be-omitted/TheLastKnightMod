# 最后的骑士

*《杀戮尖塔》角色 Mod · The Last Knight*

> 麦种播入高塔，高塔吞噬麦种。无情的高塔肆意屠杀，拒绝生命。生命需要骑士，骑士便会挺身而出！

## 简介

**“杀死高塔，杀死高塔！！”**

本 Mod 的灵感来自《明日方舟》中的“最后的骑士”，为《杀戮尖塔》加入一位可玩角色：四十余张卡牌、四件专属遗物，以及特殊的角色外观。

- **意志**：骑士的精神与执念，支配躯骸的绝对意志，能够抵消模肢的负面影响。
- **模肢**：源自海嗣的进化之力，客观的肉体本能，能为战斗带来多种可触发效果。

高塔仍在，海潮未退。

骑士已经出发。

## 作者的碎碎念

这是我最近水月肉鸽初见二结局，被骑士肘飞之后打算写的mod。

因为是蓝色系角色，所以原本是打算设计一个“要启动”“大卡组”“可无限”的角色，这样就能爽玩我最爱的无限而且不用担心被安东尼弄了（）。

但是嘛，卡组设计的复杂度有点高了，很难说完成了最初的目标。卡组牌数偏少，后续将进行数轮调整与更新，以贴合原目标。
